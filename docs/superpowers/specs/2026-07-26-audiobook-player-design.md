# Дизайн: Android-приложение «Аудиокниги» (личное)

Дата: 2026-07-26
Статус: утверждён (brainstorming)

## 1. Назначение и границы

Личное Android-приложение для прослушивания аудиокниг, скачанных на устройство. Только Android, только для одного пользователя, всё хранилище локально.

Ключевая фишка: **удаление аудиофайла с устройства не удаляет книгу из каталога.** Карточка книги с метаданными, прогрессом, закладками, оценкой, полками и историей переживает удаление файлов и может быть «оживлена» позже.

**В скоупе:**

- Универсальный плеер: mp3-папки, m4b с главами, одиночные файлы (mp3/m4a/opus/flac/ogg) — авто-определение.
- Автоскан выбранной папки (SAF) + ручной импорт не требуется (только автоскан).
- Все функции плеера: скорость 0.5–4x, таймер сна, закладки с заметками, настраиваемая перемотка, MediaSession (экран блокировки, наушники), автопауза, эквалайзер, volume boost, фоновое воспроизведение, авто-резьюм.
- Богатый каталог: метаданные + обложка + прогресс + закладки + оценка + отзыв + теги + полки/коллекции + история (даты добавления/прослушивания, статусы).
- Метаданные: из тегов файла + ручное редактирование + онлайн-обогащение (OpenLibrary/Google Books).
- Локальное хранение (Room + кэш обложек). Без облака, без синхронизации, без экспорта/импорта.

**Вне скоупа:**

- URL-загрузка книг (пользователь качает файлы сам через браузер/торент-клиент).
- Облачная синхронизация и бэкап.
- iOS, десктоп, web.
- Поиск по «Audible» как источнику (нет официального API + ToS-риски).

## 2. Технологический стек

- Kotlin + Jetpack Compose (UI).
- Media3 (ExoPlayer + `MediaSessionService`) — воспроизведение, фон, MediaSession.
- Room — каталог, прогресс, закладки, полки, теги, кэш метаданных.
- Hilt — DI.
- SAF (`ACTION_OPEN_DOCUMENT_TREE` + `takePersistableUriPermission`) — доступ к папке скана.
- WorkManager — периодический рескан + фоновый импорт метаданных.
- Coroutines/Flow — асинхронность, состояние.
- Compose Navigation — навигация.
- OpenLibrary REST + Google Books API (опциональный ключ) — онлайн-метаданные.

## 3. Архитектура (Подход A — clean single-module)

Один Gradle-модуль `app` с послойной структурой пакетов:

```
com.nikit.audiobook
├── app/                  # Application, Hilt, навигация
├── domain/
│   ├── model/            # Book, Chapter, Bookmark, Shelf, PlaybackState, Progress, Tag...
│   └── usecase/          # AddBook, DeleteBookFiles, SearchMetadata, StartPlayback...
├── data/
│   ├── db/               # Room: сущности, DAO, миграции
│   ├── saf/              # SAF document tree, watchdog папки
│   ├── repo/             # BookRepository, ShelfRepository, ProgressRepository
│   └── cover/            # Кэш обложек (внутреннее хранилище)
├── metadata/
│   ├── tags/             # Чтение ID3/MP4-тегов (MediaMetadataRetriever)
│   ├── chapters/         # Парсинг глав из m4b (Media3 MetadataExtractor)
│   └── online/           # OpenLibrary/Google Books поиск + кэш
├── player/
│   ├── service/          # Media3 MediaSessionService (фон, Foreground)
│   ├── controller/       # MediaController-обёртка, состояние в StateFlow
│   ├── effects/          # Эквалайзер, volume boost, speed
│   └── sleep/            # Таймер сна
└── ui/
    ├── theme/            # editorial_calm: цвета, типографика, формы
    ├── library/          # Библиотека/каталог (полки, фильтры)
    ├── book/             # Карточка книги + детали + редактирование метаданных
    ├── player/           # Плеер-экран + мини-плеер
    ├── shelves/          # Полки/коллекции
    └── settings/         # Папка скана, тема, перемотка, эквалайзер
```

**Принципы:**

- UI (Compose) видит только `domain`-модели и use-case’ы; Room/SAF/Media3 спрятаны за репозиториями.
- Плеер — отдельный `MediaSessionService`; UI общается через `MediaController`, состояние стримится в `StateFlow`. UI не держит playback-логику.
- Метаданные — конвейер: теги файла → (если неполно) онлайн-поиск → ручное переопределение. Каждый шаг кэшируется.
- SAF: одно разрешённое дерево, watchdog через `DocumentFile` + периодический рескан `WorkManager`.

## 4. Модель данных (Room)

Книга имеет две жизни: «живая» (файлы есть) и «карточка» (файлы удалены). Различаются флагом `filesPresent`.

### `Book`

- `id: UUID`, `title`, `author`, `series`, `seriesIndex`, `genre`, `description`, `year`
- `coverPath` — путь в кэше обложек; переживает удаление аудиофайлов
- `sourceUri` — persisted SAF URI папки/файла для рескана
- `filesPresent: Boolean`, `fileType: enum(SINGLE_FILE | FOLDER | M4B)`
- `totalDurationMs`, `addedAt`, `lastPlayedAt`, `completedAt`
- `rating: 0..5`, `review`, `status: enum(READING | COMPLETED | DROPPED | PAUSED | WISHLIST)`
- `sourceKind: enum(LOCAL_FOLDER | LOCAL_FILE)`, `originalPath`
- `manuallyEdited: Boolean` — защищает поля от перетирания при рескан

### `Chapter`

- `id`, `bookId`, `index`, `title`, `startMs`, `endMs`, `filePath`
- Для `FOLDER`: глава = один mp3-файл. Для `M4B`: embedded chapters, `filePath=null`. Для `SINGLE_FILE`: одна виртуальная глава на всю длительность.

### `Bookmark`

- `id`, `bookId`, `positionMs`, `title`, `note`, `createdAt`

### `PlaybackProgress`

- `bookId` (PK), `positionMs`, `chapterIndex`, `percent`, `lastPlayedAt`
- Одна запись на книгу; авто-резьюм читает отсюда.

### `Shelf`

- `id`, `name`, `colorHex`, `sortIndex`

### `ShelfMembership` (m2m)

- `shelfId`, `bookId` (составной PK)

### `Tag` + `BookTag` (m2m)

- Свободные теги на книгу, отдельно от полок.

### `MetadataCache`

- Кэш онлайн-поиска (запрос → ответ), чтобы не дёргать API повторно.

### Семантика удаления

- **«Удалить с устройства»:** `filesPresent=false`, обнуляются `sourceUri`/`filePath` глав. **Сохраняются:** `Book`, метаданные глав (title/start/end без `filePath`), `Bookmark`, `PlaybackProgress`, обложка, оценка, отзыв, теги, полки, история.
- **«Удалить из каталога навсегда»:** явное действие с подтверждением → каскадное удаление записи и всех связанных сущностей.

## 5. Плеер и фоновое воспроизведение

**Движок:** Media3 `MediaSessionService` (текущий стандарт Google).

### `AudioBookPlaybackService : MediaSessionService`

- Foreground-сервис с notification: обложка, название/глава, play/pause, перемотка ±, скорость.
- Очередь = главы книги как `MediaItem`-ы; gapless-склейка для m4b и папок mp3.
- Персист позиции: каждые ~10 сек и при паузе/остановке → `PlaybackProgress` в Room (через repo). Авто-резьюм при старте читает последнюю позицию и `seekTo`.
- `speed`, `volumeBoost`, `eq`-настройки — на книгу (опционально) или глобально.

### `PlayerController` (UI-процесс)

- Обёртка над `MediaController`, стримит `StateFlow<PlayerUiState>`: `isPlaying`, `currentBook`, `currentChapter`, `positionMs`, `durationMs`, `speed`, `sleepTimerRemaining`.
- UI подписывается, без ручных коллбэков в ViewModel.

### Эффекты

- **Скорость:** `PlaybackParameters.setSpeed(0.5–4.0)`, pitch не меняется. Preset’ы + слайдер.
- **Volume boost:** `ExoPlayer.audioVolume = 1.0..2.0` (программное усиление выше 1.0). Ползунок + «по умолчанию для тихих книг».
- **Эквалайзер:** `android.media.audiofx.Equalizer` поверх `audioSessionId`. Preset’ы (Bass Boost / Voice Clarity / Flat) + ручные полосы. Цель — разборчивость голоса.
- **Перемотка:** настраиваемый шаг (±10/±30/±60 сек), в notification и UI.
- **Auto-pause:** Bluetooth-disconnect / `AUDIOFOCUS_LOSS_TRANSIENT` / `BECOMING_NOISY` → пауза. Авто-резьюм при переподключении — опция.

### Таймер сна

- Preset’ы: 5/15/30/60 мин + «до конца главы» + «до конца книги».
- Custom action MediaSession — управление из notification. Остаток стримится в UI. Срабатывание → `pause()` (не `stop`), позиция сохраняется. `AlarmManager.setExactAndAllowWhileIdle` для точности в Doze.

### Закладки

- Постановка с текущей позиции → диалог (title + note). Переход по тапу из карточки/плеера. Редактирование/удаление. Хранятся в Room, переживают удаление файлов.

## 6. Автоскан папки и конвейер метаданных

### Автоскан (`data/saf`)

- Первый запуск: выбор папки через `ACTION_OPEN_DOCUMENT_TREE`, `takePersistableUriPermission` (переживает перезагрузку).
- `DocumentFile`-обход дерева рекурсивно. Эвристика определения книги:
  - Папка с ≥1 аудиофайлом → книга `FOLDER` (аудиофайл = глава, сортировка natural-order). Не-аудио файлы в папке (обложки jpg/png, .txt, .cue, .nfo) игнорируются и не мешают определить книгу.
  - Одиночный `.m4b`/`.mp3`/`.m4a`/`.opus` вне такой папки → `M4B`/`SINGLE_FILE`.
  - Папки-книги внутри папки → каждая отдельная книга; разрозненные файлы в корне → каждый отдельная книга.
- Дедуп по `(sourceUri|relativePath)` + по `(title+author)` из тегов.
- При рескан: новый файл → новая книга; исчезнувший файл → `filesPresent=false` (запись не удаляется).
- Запуск: `WorkManager` `PeriodicWork` (~раз в час) + ручной «Обновить» + лёгкая проверка `lastModified` корня в `onResume`. Realtime-вотч на SAF невозможен — периодический опрос.

### Конвейер метаданных (`metadata/*`)

Пайплайн для каждой книги, последовательно, каждый шаг кэшируется:

1. **Теги файла** — `MediaMetadataRetriever`: title, author/artist, album, genre, year, embedded art → обложка.
2. **Главы** — для m4b: встроенные главы через Media3 `MetadataExtractor` (MP4 chapter atoms). Для папки mp3: глава = файл, title из тегов или имени. Для одиночного файла: одна виртуальная глава.
3. **Онлайн-обогащение** — только если шаг 1 неполон (нет обложки ИЛИ нет описания). Поиск по `(title, author)`:
   - OpenLibrary (без ключа, бесплатно) — основа.
   - Google Books (без ключа есть лимиты; опционально ключ пользователя) — дополнение.
   - Результаты → диалог выбора или авто-применение при уверенном матче. Кэш в `MetadataCache`.
4. **Ручное переопределение** — экран редактирования карточки; `manuallyEdited=true` защищает поля от перетирания при рескан.

Онлайн-поиск идёт по нормализованному названию (lowercase, без мусора «аудиокнига/mp3/год» из имён файлов) — regex-чистильщик.

**Производительность:** скан + метаданные — в `WorkManager` (фон, не блокирует UI), прогресс в библиотеке (snackbar «Импортируется: N книг»). Обложки ресайзятся до ~600px, хранятся во внутреннем кэше.

## 7. Экраны, навигация, визуальный язык

### Навигация

Compose Navigation, bottom-bar 3 таба + плеер оверлей:

```
Библиотека  |  Полки  |  Настройки
              + карточка книги (bottom-sheet)
              + редактор метаданных
              + плеер-экран (из мини-плеера)
```

**Мини-плеер** — приклеен снизу над bottom-bar, пока играет. Тап → полноэкранный плеер. Содержимое: обложка-миниатюра, название/глава, play/pause, перемотка ±.

### Экран «Библиотека» (главный)

- Список/сетка всех книг — живых и карточек без файлов (плашка «нет на устройстве»).
- Фильтры: статус, наличие файлов, полка, тег, жанр.
- Сортировка: недавно слушал / добавлено / название / автор / прогресс / оценка.
- Поиск по названию/автору.
- FAB «Обновить библиотеку» + индикатор импорта.

### Экран «Карточка книги»

- Обложка крупно, метаданные, статус, оценка, полки, теги, описание.
- Блок «Прослушивание»: прогресс-бар с процентом, Play/Continue (с позиции), список глав с длительностью и отметкой прослушанного, закладки с переходом.
- Действия: «Удалить с устройства», «Вернуть на устройство» (если `filesPresent=false`), «Редактировать метаданные», «Удалить из каталога навсегда» (с подтверждением).

### Экран «Плеер» (полный)

- Обложка-герой, название/глава, scrubber с метками закладок, время/длительность.
- Контролы: перемотка ±, play/pause, след./пред. глава, скорость, таймер сна, закладка-в-один-тап.
- Лист: главы, закладки, эквалайзер/preset’ы, volume boost.
- Sleep-timer chip сверху с остатком.

### Экран «Полки»

- Создание/переименование/удаление полок, выбор цвета.
- Внутри полки — книги, drag-сортировка (`sortIndex`).
- Предустановленные при первом запуске: «Читаю», «Прочитал», «Брошено», «Любимое» (удаляемы).

### Экран «Настройки»

- Папка автоскана (SAF picker), интервал рескана, «Сканировать сейчас».
- Тема (Светлая / Тёмная / Система), акцентный цвет.
- Шаг перемотки, поведение при disconnect наушников/Bluetooth, авто-резьюм вкл/выкл.
- Эквалайзер/volume boost/скорость по умолчанию.
- Онлайн-обогащение вкл/выкл + ключ Google Books (опционально).
- «О приложении» + версия. (Экспорта нет — выбрано «только локально».)

### Визуальный язык (editorial_calm)

- Светлая: тёплый бумажный фон (~`#F6F1E7`), текст тёмно-серый. Тёмная: глубокий slate (~`#1A1B1F`), не чисто-чёрный.
- Один акцентный цвет (на выбор; по умолчанию приглушённый terracotta/охра).
- Типографика: serif для названий книг и заголовков полок; sans (Inter/Roboto) для интерфейса. Числа — tabular-figures для времени/длительности.
- Карточки с тонкой рамкой, мягкой тенью, скруглённым радиусом. Без градиентов, glassmorphism, sparkles, «AI»-лоска.
- Обложки — главный визуальный элемент, показываются крупно и ровно.

## 8. Обработка ошибок

- **SAF/файлы:** отозванный URI → баннер «Нет доступа к папке» + переход в настройки. Файл пропал между сканами → `filesPresent=false`. Файл пропал во время воспроизведения → graceful pause + уведомление, без краша. Нечитаемые теги → fallback на имя файла.
- **Онлайн-метаданные:** нет сети → пропускаем шаг 3, данные из тегов; ручное «Обогатить» позже. Пустой/неоднозначный ответ → диалог выбора или пропуск. Rate-limit/ошибка → backoff + кэш. Никогда не блокирует импорт.
- **Плеер:** AudioFocus transient loss → пауза, regain → авто-резьюм (опция). `BECOMING_NOISY` → пауза. Corrupted-фрагмент → skip главы + snackbar. Service-краш → авто-restart, позиция из последнего прогресса (≤10с потеря).
- **Room:** явные `Migration` объекты, **не** `fallbackToDestructiveMigration` (каталог ценен). Ошибка БД → сообщение + лог.
- **Таймер сна:** `AlarmManager.setExactAndAllowWhileIdle` (пользователь явно завёл таймер, допустимо в Doze).

## 9. Тестирование

- **Unit (Robolectric/JVM):** доменные модели, эвристика определения типа книги из структуры папок, regex-чистильщик названий, матчинг глав при «оживлении» записи, дедуп автоскана, маппинг тегов→модель.
- **Repository (in-memory Room):** CRUD книги, **сценарий «удалить с устройства» vs «удалить из каталога»** (ключевой), прогресс, полки, теги.
- **PlayerController:** фейковый `Player`/`MediaController` — позиции, скорость, sleep-timer, сохранение прогресса.
- **UI (Compose):** «удалил с устройства → карточка осталась с плашкой», фильтры/сортировка, диалог удаления (два действия не перепутать), разворачивание плеера.
- **Интеграционный smoke (эмулятор):** сервис + воспроизведение тестового m4b/mp3 из ассетов, прогресс и закладки.
- **Не автоматизируем:** системный SAF-picker, онлайн-API (мокаем), эквалайзер (аппаратно-зависим).

### Ключевой acceptance-сценарий
>
> Добавить книгу → дослушать до 80% → «Удалить с устройства» → книга исчезает из «живого» списка, остаётся в каталоге с плашкой «нет на устройстве», прогресс 80%, оценка, закладки, полки сохранены → «Удалить из каталога навсегда» с подтверждением → запись удалена каскадно.
